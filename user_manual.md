CamExp User Guide

For Clients:
1. Register as 'client'.
2. Manage profile: Edit bio, location.
3. Search services/experts: Use search bar, filtered by location (geolocation).
4. Request service: Create request post, contact via chat.
5. Receive notifications: For responses, payments.
6. Make ratings/reviews: After completion.
7. React to posts: Like service listings.
8. Project management: Dashboard for status, schedule meetings.
9. Payments: Choose MTN/Orange, enter phone/OTP, approve via USSD.

For Experts:
1. Register as 'expert'.
2. Manage accounts/profiles: Edit details.
3. Manage service listings: Create/edit services.
4. Respond requests: Accept client requests, chat.
5. Manage payments: Receive disbursements (code has placeholder for payout).
6. Schedule: Use calendar for events.
7. View ratings.

Admin: Manage all via /admin/.

Troubleshooting: For real-time chat, ensure WebSocket connection. For payments, use sandbox mode first.
